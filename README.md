# Enhanced Music Queue

This project is an enhanced version of a Python data structures lab.  
It implements a command-line music queue system using a doubly linked list.

## Features

- Add song to queue
- Add song after current song
- Add song to the end
- Play next song
- Play previous song
- Remove current song
- Clear queue
- Search inside queue
- Jump to a song by position
- Show remaining duration
- Move current song to the end
- Toggle repeat-all mode
- Search songs using YouTube Music API

## Tech Used

- Python
- Doubly Linked List
- ytmusicapi
